# ShortKing Database

## Setup

1. Open the Supabase project.
2. Go to SQL Editor.
3. Create a new query.
4. Copy the contents of `schema.sql`.
5. Run the SQL.
6. Verify the tables under Table Editor.

Tables:

- profiles
- urls
- click_events
- reserved_aliases

`seed.sql` is optional and should only be used for development/testing.

Never put passwords, API keys, service-role keys, or other secrets in these files.
